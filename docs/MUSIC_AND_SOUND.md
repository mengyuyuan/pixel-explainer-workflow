# 配乐、音效和混音

以下为本项目制作要求与试排起点，不是对参考片曲名、BPM、音源或混音设置的推测。参考声音的实证边界见 [研究记录](REFERENCE_JAYCEN_LEVERAGE.md#声音证据与局限)。

## 四类声音各负其责

| 轨道 | 职责 | 不能用来代替什么 |
| --- | --- | --- |
| 旁白 | 因果、条件、人物视角、判断 | 不能让画面所有机制都靠旁白补完 |
| 音乐 | 维持段落情绪和整体推进，连接章节 | 不能用短提示音数量冒充配乐 |
| 动作音效 | 接触、受力、流转、碰撞和改变 | 不能给每条字幕、每个切镜自动打点 |
| 概念提示 | 少数新发现、阈值触发、总结收录 | 不能每次数字变化都响胜利音阶 |

环境声按场景需要另设；纯图解可以不加。先保证旁白可懂，再让真正重要的动作可辨，最后决定音乐多丰满。旁白沿用本片已选声线，情绪由语义、重音和停顿控制，不靠全段压低音高制造“专业”。

## 配乐先写段落意图

在分镜声画表填写音乐段落、进入/退出条件、密度变化、留白和收束，不等画面做好后随机找一条歌铺底。下面是可选方案，按选题删改：

| 段落职责 | 可试排的音乐处理 |
| --- | --- |
| 开头矛盾 | 简短稀疏动机，留出提问尾句；事故画面无需堆满低频冲击 |
| 建立例子 | 稳定、轻量的节奏背景，旋律不过密，避免抢数字和名词 |
| 机制升级 | 保留主题，改变配器、低音或音符密度；不必每章换一首歌 |
| 关键后果 | 减层、短暂抽空或单次强调，给结论和反应留下空间 |
| 回到开头 | 原动机变奏或熟悉的音色回归，支持结构上的回扣 |
| 收束 | 减少活动，最后短句后完成乐句并淡出，别截断尾音 |

像素画面不强制配整首高密度 8-bit 游戏音乐。需要芯片风格时，短脉冲承担轻旋律、三角波承担低音、带限噪声承担节奏是一个起点；控制高频和重复旋律，持续几分钟仍须可听。音色选择和 BPM 依旁白密度与情绪决定，不从画面风格反推参考曲目的参数。

循环按乐句边界衔接，避免断点和点击声。长片在论点转折处安排增减层、休止或变奏；不是每隔固定秒数机械换曲。音乐需要时可以提前铺垫，但动作接触声必须优先对准画面，不能为了落在拍点上让拿取、落地错时。

每条音乐记录来源、作者、许可和所需署名；原创记录生成或制作来源。参考片混音不可直接当作背景音乐截取使用。

## 8-bit 音效按材料和意义设计

先区分真实动作、解释动作和 UI 事件，再选音色。一次复杂动作可以由起音、主体和尾音组成；不必每层都明显可闻。

| 事件 | 音色与包络试排 | 同类变化 |
| --- | --- | --- |
| 轻物落桌、按钮接触 | 极短脉冲起音 + 低三角波主体 | 接触力度、材料、距离 |
| 纸张、凭证、标签翻动 | 短带限噪声 + 收尾轻击 | 翻动时长、张数、落稳力度 |
| 金属币、硬件碰撞 | 较亮短脉冲 + 短衰减泛音 | 单枚与一簇、近远、先后落点 |
| 受力、断裂、坍塌 | 低频主体 + 噪声碎裂 + 零星余响 | 起裂、破坏、落地分阶段，避免每帧爆炸 |
| 连续机器或步行 | 触点驱动短音、间隙与渐弱 | 速度、力度、左右脚或机件相位 |
| 越界、失败 | 稀疏低音或短降落音型 | 只留给状态真正改变的时刻 |
| 新概念收录 | 独立短音型 | 与钱币、脚步、普通按钮区分 |

同类反复出现时，先改变力度、长度和密度，必要时使用多个源变体。随机选择必须固定种子并受动作约束，保证渲染可重复；不能每次完全随机声像和音高。变调同一个 beep 不能算多个材料音色。

循环工作演到观众理解后稀疏化，让下一次明显声音落在新后果上。合成音若在手机扬声器中太刺或太薄，调整主体频段和包络，不能一概降低到听不见。

## 混音与退让

保留独立轨，按旁白句组自动化增益。可从音乐在有声段比旁白的短时平均电平低约 18–24 dB 试排；比较必须用相同窗口，这只是初始电平关系，不能把文件峰值当作听感。实际音色、配器和扬声器不同，仍需合画面试听。

需要 ducking 时可从降低音乐 3–6 dB、约 30–80 ms 进入、250–600 ms 恢复试排。句内很短的停顿保持退让，防止每个字间音乐抽动。重数字、关键定义和低声结论可单独减配器或下拉，不依赖压缩器自动猜含义。旁白休止期间也不必把音乐突然推到前景。

动作音效按重要性单独定增益与频段，不用一个统一倍率把所有声音放大。明亮瞬态尤其要避开旁白辅音密集处；必须同时发生时降低冲突频段或压缩尾音，不能任意挪走关键接触。

中间总线用浮点，限幅只用于最终峰值控制，补偿处理延迟。成片可从 -16 至 -18 LUFS、真峰值不高于 -1 dBTP 起步，根据交付要求调整。参考片的混合轨 RMS、LUFS 或峰值都不能还原独立 BGM 的音量。

## 听审与研究边界

至少比较耳机、普通小扬声器或手机、单声道，以及较低播放音量。合画面完整听一遍，记录具体时间：哪个词听不清、哪个动作缺声、哪里重复、哪次音乐恢复突兀、哪个提示过响。问题修复后重听受影响段落和衔接。

工具只提供波形、频谱、ASR 或响度时，可以报告节奏候选、能量变化和文本落点，不能据此声称音色自然、音乐好听或混音通过。左右声道差分不是分离出来的音乐轨；声源分离也会有语音泄漏和伪影。没有实际听审能力时保留未验证状态和可试听文件，其他制作继续完成，不编造曲名、乐器、节拍或原作者制作软件。
