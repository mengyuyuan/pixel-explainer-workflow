# 动作、声音和检查细则

## 参考片怎么拆

先确认参考作品身份和完整时长，再分别记录叙事、视觉、连续动作和声音的检查覆盖。全片概览可以发现结构，密集抽帧可以分析运动；ASR 可以辅助定位台词；它们都不能冒充正常速度完整观看与听审。观察不到的项目明确留空或标未验证。完整案例见 [Jaycen《杠杆》研究](REFERENCE_JAYCEN_LEVERAGE.md)。

先正常速度看完整语义段，记录人物正在做什么及结果。再对走路、交接、操作、反应等关键动作连续抽帧，必要时从每秒 8–12 帧开始，细查时用原始帧率。记录起止时间、姿势变化、道具附着、停顿和声音落点。

区分角色换姿势、整体平移、道具移动、镜头运动。单张截图不能证明有角色动画，少量抽帧不能冒充正常速度观看。只复用可见的表演方法，重新制作本片的角色和场景。

## 精灵表制作与使用

1. 为主角按剧本列具名姿势 ID。复杂人物故事可从 15–25 种准备，简单图解按实际动作选用；数量不作为验收依据，不能把不同配色当成不同姿势。
2. 绘制角色基准：头身比例、调色板、衣服、左右朝向、脚底基线。精灵表每格留透明间隔，手脚不得跨入相邻格。
3. 走路四个阶段分别检查腿的前后关系、脚掌接触和手臂摆动。可以从每秒 8–12 次换帧试排，最终按角色走过的距离调整；输出帧率仍保持项目帧率。
4. 同一角色切换姿势时保持脚底定位。抓取和携带姿势保存手部锚点；代码用锚点绑定道具，不凭每帧目测另放一个坐标。
5. 逐个查看透明边缘、漏肢、重复姿势、角色变脸、比例变化和相邻格串入。先修图集，再用于全片。
6. 在独立时间轴上试播动作，再接入分镜。测试向前播放、倒退跳转和随机时间定位，不出现重叠旧姿势或消失一帧。

## 交互动作的分解

| 场景 | 必须看见的过程 | 接触与结果检查 |
| --- | --- | --- |
| 织布 | 靠近织机、手握操作处、前推、回拉、重复工作、收手 | 手与操作杆共同运动；梭子和出布随工作响应；人物离开后结束该操作 |
| 拿布 | 转向布、伸手、抓住边缘、托起、携带 | 接触前布留在原位；托起后跟随双手；走路时布不穿过身体 |
| 验货 | 接过布、展开、低头看或摸边缘、比较、作出判断 | 同一块布身份连续；手贴着检查处；判断出现在检查之后 |
| 翻价签 | 看向价签、伸手、碰到边缘、翻动、松手 | 价签转动发生在接触后，松手后落稳；人物视线跟随结果 |
| 拒绝购买 | 看商品和价格、停顿、摇头或摆手、转身、走开 | 拒绝姿势先于离开；转向与步行方向一致；卖方随后作出反应 |
| 递钱或交货 | 持有、递出、接收方伸手、接住、发送方松手 | 道具的持有者只在接触后切换，不同时出现在双方手上 |
| 升级工具 | 看旧工具、拿起或装入部件、接好、试用、看到效率变化 | 部件由人物操作进入安装位置；速度或产出变化发生在安装完成后 |

每镜只安排台词和情节需要的过程，不强行把整张表塞进每个镜头。拿取、交接等因果节点要清楚，其余重复工作可以压缩或切到结果。

## 场景与节奏

- 人物在同一场景保持身份、左右关系和地面基准。移动可以带镜头，但背景运动不能掩盖脚步滑动。
- 展示手部操作时调整构图到接触点看得清，避免人物缩得过小，也避免道具遮住操作手。
- 相邻镜头需要衔接时，对齐人物或共享道具的方向、位置与动作阶段。硬切用于明确换地点、换时间或换解释任务。
- 表情变化接在事件后，给反应和结果留观看时间。时间不够时删掉次要动作，不把全部动作加速到不可辨认。
- 字幕位于安全区，避开脚部动作、价签和读数。必要标签保留，长段解释交给旁白，不能让标题替代故事。

## 全片重复检查

分镜确定后、生成整片旁白和长时间渲染前，按时间顺序检查整条故事。每个解释段记录：台词区间、新增信息、画面里的事件或状态变化、复用镜头及必要性。可以放在已有分镜表里，不需要另建报告。

- 若删掉某段动画后，只剩旁白在推进，而画面仍是前一段的同一工作循环，应重写该段画面或合并内容。
- 同一个场景可以继续使用，但人物目标、物件关系或结果须随新内容推进。只换标题、人数、颜色、数字或缩放，不能掩盖相同的动作和解释；数字变化本身就是要解释的因果结果时，保留必要对照即可。
- 持续劳动只演到观众看懂，再切到产出、交接、选择或后果。不能让织机推拉、同行排队、群像工作或标尺变化成为后半段通用背景。
- 回顾只短暂指回已知结论，随后收束或进入新的后果，不重新跑一遍接近、操作、产出全过程。不要为避免重复而硬加与台词无关的动作或随机换场。
- 例如讲工具升级：首次演出安装和试用；讲普及时可演出邻居观察、购买和换机；讲旧工具持有者处境时，演出库存、交易或人物选择。每个场景都应服从本片实际论点并核对事实，不能把这些例子当成固定镜头清单。

导出后把全片按时间排成接触表，检查视觉构图是否大段雷同，再正常速度连看后半段，记录重复区间与处理结果。接触表只能发现候选重复，不能替代动态审看；长时间停留用于读数或理解时也不必强加动作。发现重复就缩短、合并或重做对应段落，不以更快循环或更多音效掩盖。若受最低时长限制，补足实质内容后重新对齐旁白、字幕、动作与音效。

## 8-bit 音效的分工

下表是起始合成方法，最终长度和强度根据实际动作调整。

| 动作 | 起始音色方案 | 配声规则 |
| --- | --- | --- |
| 脚步 | 约 50–100 ms 的低三角波冲击，少量短噪声 | 对准脚掌接地，远离镜头时逐渐减弱；不替每个循环机械打点 |
| 织机、推拉 | 短脉冲与中低频噪声组成机械接触 | 区分推、拉和落稳；演示数个周期后让位给旁白 |
| 布料 | 约 120–350 ms 的柔和带限噪声 | 跟随展开、拿起或摩擦，避免用高音提示声表达布料 |
| 翻牌、纸张 | 短噪声翻动，末尾轻触地或碰撞 | 起音对准开始翻动，落点对准落稳，不拆成一串音乐音符 |
| 齿轮、安装 | 短促机械冲击与少量高频噪声 | 配实际咬合或卡入，不给持续旋转铺满撞击声 |
| 发现、升级 | 短方波音型或和弦 | 只用于重要转折，同一音型不连续占据普通动作 |

同一音色的变化先来自动作差异：力度、节拍、距离、声像、长度，再考虑轻微音高变化。不同动作若仍像同一个按钮，重做音色结构，不能只更换音高。

混音保留旁白、音乐、动作音效和概念提示的独立轨与独立增益；中间文件使用浮点格式，避免限幅前已削波。限制峰值时补偿处理延迟。可以用约 -16 至 -18 LUFS、真峰值不高于 -1 dBTP 作为口播混音起点，但仍须检查实际旁白和音效是否清楚；这些数值不是听感验收结论。音乐编排、退让和音效变体按 [配乐与声音规则](MUSIC_AND_SOUND.md) 执行。

## 导出后的检查顺序

1. 完整解码，核对尺寸、帧率、帧数、时长和音轨。
2. 按镜头检查开始、动作中间、接触、结果四类时刻；密集动作增加检查点。
3. 正常速度看完每镜及前后衔接，检查动作能否看懂、走路是否滑步、拿取是否穿模、结果是否有停留；按全片重复检查连看后半段，不能只验单镜动作而漏掉大段重复。
4. 合画面听完整混音，记录重复、抢旁白、听不见、接触偏移或尾音拖延的具体时刻。
5. 按记录返修并检查受影响范围。任何混音或时间轴变更后，重新检查最终编码的同步与对应动作。
6. 无法完成动态观看或听审时，将该项记录为未验证并保留预览状态，不用截图或响度报告替代。
