# 项目扩展与待精修项

完整上游见 [Claude Video Studio](../upstream/claude-video-studio/SKILL.md)。导入原件保持逐字节不变；本页只记录本项目的差异和后续工作，不替换上游正文。

## 现有项目约定

- 《资本论 / 马哲》系列采用 16:9；按具体选题做超过 1 分钟或超过 3 分钟的内容，依据实际旁白安排时长，不以循环画面凑时间。
- 该系列已明确选择纯像素动画，不插入外部视频。参考作品只用于拆解。历史电梯演示保留了有许可的实拍片段，不能自动带入新片。
- 默认 GPU 优先，无可用设备时才回退 CPU。现有 TTS 入口按 CUDA → MPS → CPU 实测；视频渲染沿用 HyperFrames 的 GPU 探测与编码回退。记录实际使用设备，不把传入参数当作已经使用硬件的证据。
- 当前系列保留已选定声线；换声线先提供少量真实试音。旁白生成后再对齐字幕和动作，修改语速时同步相关时间轴。声音、模型与远程机器配置不随技能导入公开。
- 当前系列的封面使用图像生成流程单独制作；封面精致度不能代替视频画面和角色表演的质量。

## 这次反馈留下的精修要求

**人物。** 旧版每人仅 6 种姿势，走路两帧差异很小，经常站着指向道具，未落实上游的 15–25 姿势及故事专属动作。下一轮依照上游补齐织布的推拉、拿布、验货、转身、拒绝、交接和情绪变化，并检查连续动作。这些是待完成的修复，不登记为已实现。

**音效。** 旧版对普通动作频繁使用相近的升降音阶，产生重复感。最近返修减少打点，以方波、三角波和短噪声区分翻牌、织机、布料、脚步等动作；普通切镜和字幕不自动配声。前 37.6 秒从 56 个事件减到 17 个只是该片的处理记录，不是所有视频的数量配额。新版尚未取得整体听感认可，不能仅因更少、更响或音色种类更多就判定通过。

**参考。** 用户提供的作品是[像素财经《通货膨胀》](https://www.douyin.com/video/7683489452466930600)。实际连续抽帧可见：约 4–6 秒拿钱走到店前，停下后钱离开手边；约 26–28 秒人物靠近箱子，钱进入、箱盖合上。它也有安静停留，不能把“每秒必须动”当作其方法。这是对成片可见行为的观察，不能据此声称知道作者使用的软件或源码。参考视频、截图和音轨不随仓库分发。
