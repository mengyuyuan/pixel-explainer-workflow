## 三条片的讲法不同

| 作品 | 解释主线 | 核心对象 | 对公共技能的意义 |
| --- | --- | --- | --- |
| 期权 | 两种结局提问 → 简化交易 → 权利、定价及另一方 → 员工情境与现实合约 → 判断条款 | 一张带稳定字段的凭证、买卖双方、同一说明板 | 道具要有规则与字段；视角转到承担代价的一方；现实迁移补条件差异 |
| 钱从哪里来 | 对比两个账户数字 → 交换与共同接受 → 库存和记录 → 商品产出 → 现实指标 → 回答开头 | 金币、金库、账本、工资卡与实物图标 | 实物、记录、范围和数量分别表示；不同关系选择不同图形 |
| AI 资本永动机 | 循环关系设问 → 产业分层 → 三方关系 → 扩大网络 → 连锁类比 → 回扣与预告 | 机构头像、带标签的边、分层卡片、相连的船 | 可以主要用网络完成解释；不必强套人物买卖故事、三层路线或图鉴收集 |

《期权》和《钱从哪里来》与《杠杆》有相近的长片骨架，AI 片则直接从关系网络进入。这四个样本支持“稳定对象、问题推进、现实映射和回扣”这一组方法，不能据此断言作者所有作品都采用同一结构。

## 《期权》：一张凭证贯穿多个解释层级

| 近似时间 | 观察 | 可迁移规则 |
| --- | --- | --- |
| 00:00–00:34 | 同类凭证对应不同结局，引出为什么价值不同 | 用需要机制解释的对照开场，不先罗列定义 |
| 00:34–01:22 | 商铺、两方和凭证建立后再给出解释路线；00:48–00:52 的连续帧看到人物入场、凭证移到中央并放大 | 人物建立视角，道具承担规则；图形放大不等于每次都有实体手部递交 |
| 01:22–03:17 | 凭证经历不同条件；说明板从权利对照变为定价任务，旧字段仍可识别 | 保留字段位置与含义，一次改变当前条件，不用每句重建场景 |
| 03:17–04:07 | 从获得权利的一方切向承担义务的一方，再引入履约约束 | 受益、成本、履行条件要闭合，不能只演好处 |
| 04:36–04:40 | 沙漏先在条件栏中突出，随后脱离槽位，移动到另一方上方，旧位置留下虚线 | 空间位置可以表现作用关系；必须说明语义，不误画成所有权转移 |
| 04:41–07:47 | 已学凭证映射到员工情境、再到现实报价；06:54–06:58 依次强调日期与价格字段 | 现实迁移沿用对象身份，同时补新增限制；焦点依次转移 |
| 07:47–08:54 | 将解释转成可核对的条款，再压缩回顾并延伸下一问 | 结尾交付判断操作，条目数量由选题决定 |

需要独立核查的内容：片中的历史案例、统计比例、雇佣条款和现实合约规则。本研究不继承其具体数字。合约的结束方式与持有人盈利情况不是同一分类，比例格即使画得清楚也不能跨口径推出胜率。

## 《钱从哪里来》：实物、记录和范围各用一种图形

| 近似时间 | 观察 | 可迁移规则 |
| --- | --- | --- |
| 00:00–01:22 | 屏幕中的事件与屏幕外的观看者分层；交换故事之后才展示待解问题 | 画框区分叙述层级；从现实切到模型时留下原问题 |
| 01:22–02:28 | 交换媒介的例子后回到已认识的人物，再追问总量变化 | 支线负责检验一个边界，结束后回到主线 |
| 02:28–03:50 | 金库与账本并列；02:47–02:51 连续帧中库存数字减少，旧存款记录仍保留 | 库存与记录分开建状态，变与不变同时可见 |
| 03:50–05:55 | 用商品数量对照解释数字含义；约 05:21–05:33，已有实物与空虚线槽形成对比，后者再被填入 | 预期、尚未发生和已经实现应有不同状态，不用一次弹入把条件抹掉 |
| 05:55–07:03 | 从故事换成范围图、比例格、并列柱；06:13–06:17，旧内框保留，新外框向周围展开 | 图形按关系选择；包含不靠搬运动作解释，示意面积不能冒充真实数量 |
| 07:03–08:36 | 路线卡先成为提醒，07:58 后进入总结，约 08:03–08:09 的抽帧可见答案依次强调，最后回到片头两个对象 | 同版式可以复用，但每次回归要增加答案或判断用途 |

不能从本片直接继承现代银行机制、当前统计口径或政策因果。它对现金和记录的故事化表示可以提供画面设计参考，实际知识仍需另查对应制度、时期与一手来源。

## AI 片：关系网络也能承担整条视频

| 近似时间 | 观察 | 可迁移规则 |
| --- | --- | --- |
| 00:00–00:18 | 三个机构节点形成循环，开头即抛出关系疑问 | 网络本身可作开场对象，不需要另造历史故事 |
| 00:19–00:51 | 产业地图逐层建立，再示意流向；00:42–00:46 多层金币同时流动 | 结构图与流量图有不同职责；我们的首次解释应优先突出当前边，不能声称参考片每条流动都逐词对齐 |
| 00:52–01:29 | 回到三角关系，依次引入关系标签与条件 | 每条边写明交易类型、时间和条件，别把不同性质的金额画成同一笔实付现金 |
| 01:30–02:10 | 原三角网络缩小、移动，逐步加入更多节点与边；01:30–01:34 连续帧支持这一过程 | 扩图保留旧拓扑和身份，先让观众定位新节点，再读新边 |
| 02:11–02:40 | 换成相连的船表现依赖；02:27–02:33 可见一端火焰与连接依次变色 | 传播要有触发和路径；该采样没有证明所有船都燃烧，更不能由类比推出真实世界必然崩塌 |
| 02:41–03:01 | 回到循环对象，简短收束并延伸到下一话题 | 短片可以回收一个主要关系，不强制多层总结与图鉴完成仪式 |

本片中机构头像多作为节点，主体运动来自边、标签、金币和网络布局；没有必要让头像持续走路、挥手。全片索引未见长片那种持续累积的右侧概念栏，顶部导航仍在。统一的视觉语言可以保留，界面模块要按解释任务删减。

原片提到的投资、采购、权益与市场判断未在此次研究中独立核实，不作为我们的事实来源。尤其要区分宣布额度、附条件承诺、分期实付和已经实现的收入。闭环关系图不等于账目守恒证明，连锁比喻也不等于确定预测。

## 稳定方法与不能固定的形式

| 观察维度 | 这些样本中可以保留的方法 | 不能直接固定的形式 |
| --- | --- | --- |
| 文案 | 一个主问题，前段结果引出后段机制，结尾回应 | 三层、三个人、同一种金融故事或统一片长 |
| 画面 | 低对比背景、清楚的主体和字幕层、稳定对象身份 | 所有元素统一缩小、每片一座城镇、每镜都有人物 |
| 动画 | 对象、条件、归属或关系发生有意义的变化 | 姿势数量、换背景数量、持续跳动或满屏流动 |
| 复用 | 老对象承担新条件、另一个视角或新答案 | 原动画只换台词，尤其在后半段重复填时长 |
| 导航 | 帮观众定位解释进程，复杂内容适度积累术语 | 全部题材套同一导航、侧栏或收集结尾 |
| 声音 | 本项目已有分轨、语义音效与段落配乐要求继续适用 | 本轮未听审，不能把这些要求冒称原片已经验证的音乐规律 |

- [核心技能](../SKILL.md)：先选解释方式；人物实体动作要求按镜头职责生效；凭证和关系有明确条件。
- [文案与画面推理](NARRATIVE_AND_VISUAL_GRAMMAR.md)：加入三种解释方式、字段与关系字典、既有关系揭示、预期状态、路线卡职责、分类口径和库存/记录区分。
- [分镜声画表](SCENE_SCORE_TEMPLATE.md)：加入解释方式、节点/边状态、跨镜关系及履约字段，检查复用到底新增了什么。

本轮改的是可执行的制作文档；没有自动改造旧视频或新增渲染器能力。既有声音规则仍需在实际样片上试听验证。下一次制作要从完整因果样段验证这些规则，不能只因文档更新就声称成片已达到参考质量。
