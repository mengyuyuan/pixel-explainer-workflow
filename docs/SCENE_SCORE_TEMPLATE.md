# 分镜声画表

这是一份制作记录格式，可合并进现有分镜，不需要重复建多套表。表格写清楚后才排动画；下列是文档约定，不是 `story.py` 已实现的新配置接口。不要把文字填表误报为视频已经生成或听审已经通过。

## 全片先记录

记录：核心问题、观众原有直觉、结尾答案、适用条件、参考来源、题材/画幅/时长/素材策略/配音选择。再写角色、对象和关系字典、章节职责、音乐段落及需要回收的开头对象。选定各段的解释方式，不能默认所有镜头都填写人物劳动。

为每个解释段填写：

| 项目 | 填写要求 |
| --- | --- |
| 文案与职责 | 句段 ID、原文、这一段解决什么问题、提出什么新问题 |
| 解释方式 | 人物交互、制度/数量模型、关系网络或其组合；为何适合；切换时保留哪个对象/字段 |
| 语音定位 | 最终声音文件或哈希、句段起止、关键语义词的真实时间；估计值标“排练”，不冒充实测 |
| 进入状态 | 对象 ID、数值、单位、持有人、状态；人物镜补位置/目标/朝向，网络镜补已显示节点、既有边、当前路径 |
| 条件与事件 | 新条件、保持不变的条件、触发事件、接触点或图形操作；区分揭示既有关系与事件新发生 |
| 变化过程 | 事件先后与持续时间、适用的人物姿势/对象轨迹/边的展开、相机职责、需要停留的结果 |
| 离开状态 | 结果数值与关系、对象去向、跨镜继承或明确重置；涉及交易时补已支付额、权益、待履约义务 |
| 文字层 | 字幕、短标签、单位、导航状态、何时收录术语 |
| 动作/概念音效 | 事件 ID、音源或合成族、变体、触发/结束、增益、声像、为何需要声音 |
| 音乐 | 主题或曲段、增减层、进入/退出、ducking 包络、留白、来源 |
| 检查 | 数字重算、关系类型/条件/时间口径、因果成立、复用增加了什么、关键帧、正常速度与听审各自状态 |

把有先后关系的事件写成 `条件说明 → 对象操作 → 状态改变 → 结果读出 → 反应/命名`。不是每镜都需要全部五项，但不能缺少结论所依赖的过程。一个工程里共用同一组事件时间，字幕、SFX 和对象动作不得各自估算。

凭证记录持有人、相对方、权利、义务、对价、期限和触发条件；网络边记录 ID、起终点、关系类型、方向约定、标签、有效时间与证据。不涉及的字段留空并写不适用。反复出现的路线卡记录本次职责与新增答案，不能把原卡原动画再次播放算作递进。

## 原创迁移示例：为什么队伍会越排越长

以下为虚构的离散服务模型，只用于示范如何把规则迁移到非金融题材；没有声称已经配音或渲染。设每步代表 10 秒、每个圆点代表一位访客，初始队列为零。该步可服务人数包括步内新到者；空间足够，不考虑离队。统一计算：`Q_next = max(0, Q + A - C)`。所有数字和圆点来自这一个状态。

| 段落/原创台词 | 状态变化与画面事件 | 语义定位与表演 | 声音意图 |
| --- | --- | --- | --- |
| 建立：“窗口每十秒能办两个人。每十秒也来两个人，队伍就不会留下来。” | 同一窗口、相同站位；两人进入，两次完成后离场。A=2、C=2、Q：0→0 | 定位“两个人”和“不会留下来”；让接待员实际完成操作，来客有等待和离开，别同时滑走 | 两个不同轻重的办结音，动作后停止；稀疏主题建立 |
| 改条件：“现在每十秒来三个人，窗口仍只能办两个。第一次，多出一个。” | 只改变到达数，窗口处理能力不变。A=3、C=2、Q：0→1 | “三个人”触发新条件；“仍”保留窗口基准；“多出一个”时队尾留下可数的访客 | 来客脚步适量，处理音保持身份；结果留白，不加胜利音阶 |
| 递进：“再过十秒，又留下一个。窗口没变慢，队伍却长到了两个。” | 从上一段继承队列，Q：1→2；旧等待者先被服务，新一轮到达与剩余关系明确 | 先见时间步，再演先进先出，最后读出队长；不用重新播放空队列的旧镜头 | 主题轻微加层，办结声不越来越响，关键结论时音乐退让 |
| 追问与解答：“那把来的人降回两个，就能立刻消掉队伍吗？还不行。每轮进两个、出两个，留下的仍是两个。” | A回到2、C保持2，Q：2→2；两位旧等待者离场，两位新到者等待，显示总量未变、身份已变 | 提问时保留旧状态，答案通过人员流转而非冻结旧人物证明 | 提问前减层，展示过程使用原动作音族；结果无需再响通知 |

这个例子允许同一窗口和同一动作代码持续复用，因为每段增加了新条件或新后果；不允许复制上一段视频只改人数标签。收尾可继续演 A=1、C=2 时 Q：2→1→0，说明积存清空需要额外余量与时间，再回扣开头的问题。

最终声音未生成前，时间字段保持排练标记。生成真实旁白后，将语义词映射到实际句段，给到达、处理、离场与结果留足可辨认时间；不能用固定百分比分摊整个镜头。

## 交付前核对

文案必须有能兑现的答案；关键对象从进入到离开有连续状态；标签和数量从同一数据产生；每次复用有解释任务；音乐与音效各有职责且来源可用。技术检查、连续观影和完整听审分别记录。参考视频研究存在未验证项时，不把它变成制作事实；历史示例未改动时，也不因技能更新就标为已达新标准。
