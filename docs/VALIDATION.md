# v0.1.0 验证记录

验证日期：2026-10-05。

- 在独立目录用锁文件重新 `npm ci`，建立新的 Python 虚拟环境并安装 `requirements.txt`。
- 默认无旁白路线从源码重新生成七种角色姿势、28 个音效、横版场景和混音，再完整渲染。HTML lint 无错误。
- 实际捕获：Windows / RTX 3060 Laptop GPU；实际视频编码标签为 `h264_nvenc`。
- 编码结果：1920×1080、30 fps、750 帧、25 秒；48 kHz 立体声 AAC。完整解码通过。
- 公开演示仅含原创合成音效，测得 -22.72 LUFS、-9.77 dBTP。响度测量不代表主观听审。
- 从这次新编码抽取有序静帧，检查横版布局、实拍署名、配重与轿厢身份、比较区和结尾。
- 在另一台已有 VoxCPM 环境的 NVIDIA 电脑上执行 `tts.py --probe`，实际选择 `cuda`，未加载模型或生成新的旁白。
- 六项设备选择测试通过：CUDA 优先、MPS 次选、没有 GPU 时 CPU 回退、GPU 探测失败的回退以及显式设备失败不静默改选。
- 混音测试使用额外生成的 44.1 kHz 立体声短音频，确认转换与 25 秒混音；31 秒输入被拒绝；之后恢复无旁白状态。这些测试音频不随仓库分发。

完整正常速度动态审看和主观听审未签通过。设备选择测试包含模拟后端；CPU/MPS 的整模型语音推理、其他操作系统整片渲染没有在本次发布中实测。VoxCPM 配音属于可选入口，不把 `--probe` 成功当作模型推理成功。
