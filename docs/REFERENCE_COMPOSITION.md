# 小人物叙事的构图对照

这是对用户提供的像素财经通胀片的具体观察，用作可选构图参考，不代表所有像素视频都必须采用同一比例。

研究原链接：https://www.douyin.com/video/7683489452466930600 。取样覆盖开头工厂到商店、存钱、借款和银行资金流向场景，并对 3.2–6.2 秒跑动段及 26–28 秒存钱段观察连续帧。只分析，不分发其画面、音轨或人物素材。

## 观察与改法

- 参考片常态人物约占完整画面高度的 10%–14%，是人工对全帧的近似读数，不是作者公开的设计参数。上一轮本项目完整故事中，人物常见为 24%–36%，开头强调镜头接近 47%，因此人物和动作显得更贴近观众。
- 参考片里的工厂、商店可以很大；小人物在建筑之间行动。重点是人物与场景的相对比例和通路，并非把所有对象都缩成小图。
- 人物、钱、柜台、箱子和价签分层承担信息。道具在接触后离手、进入箱子或出现在柜台，变化集中在当前讲述的事情上，其他对象会停住。
- 常用稳定的横向舞台，大部分解释由物件、数字和人物位置改变完成。并不是一直用近景人物或持续运镜。
- 动作研究的局部裁剪图看起来会把人物放大，不能据此确定实际构图比例。应把双方完整视频帧归一到同样画幅后比较。

默认动作模板采用 64/540≈12% 的人物高度，操作细节示范采用 128/540≈24%。放大时同时调整人物、工具、站位和手部接触，不单独拉大人物。要做其他风格，按该项目的叙事与可读性重新选择比例。

这份记录基于画面和连续帧观察；没有据此宣称完成参考片的音轨分析或知道其实际制作软件。
