# 文案与画面推理

适用于以人物、道具和图解解释机制的像素视频。目标是让观众从画面变化理解结论，而不只是听懂旁白。参考来源与观察范围见 [逐段研究](REFERENCE_JAYCEN_LEVERAGE.md) 和 [多作品对照](REFERENCE_JAYCEN_COMPARISON.md)；下列是本项目的制作规则，不声称是原作者的工程规范。

## 先确定一条可演出的解释线

写脚本前确定四件事：观众原本怎么想、哪个可见结果与直觉冲突、需要补上的机制、理解后能判断什么。用一句问题贯穿全片；不要把相关知识点都塞进来。

开头优先展示具体处境或反常结果。人物故事写清目标、阻碍和后果；模型或网络写清哪个主体受何约束、哪种关系需要解释。悬念必须有可验证的答案；不能先夸大事故再用无关概念收尾。

若内容有多层机制，先给观众一张简短路线图，再逐层展开。层数由解释需要决定。每层按以下逻辑检查，而不是强制采用固定句式：

1. 从上一层的结果提出一个合理追问。
2. 在已认识的角色和对象上只引入需要的新条件。
3. 演出操作、过程或限制带来的变化。
4. 用对照排除一个常见误解。
5. 给已经看懂的现象命名，再进入下一问。

例如观众刚看懂“速度提高”，下一问可以是“为什么总耗时仍然没少”；下一镜应揭示等待或转运限制，而不是再演一次加速。转折要补机制，不靠“但是更可怕的来了”反复吊胃口。

结尾回到开头同一对象或处境，用已经学会的机制回答问题。总结压缩成判断步骤，避免重新讲完整例子。连载预告只提出一个自然延伸的问题，不抢走本集答案。

## 先选解释方式，再选动画

下列方式按段落选择，可组合，不是三种必须齐备的章节。姿势表、转场和配乐都在解释任务确定之后安排。

| 主要问题 | 适合的方式 | 状态变化与验收 |
| --- | --- | --- |
| 某人做什么选择，怎样操作，得到什么后果 | 人物交互：持续角色、场景和关键道具 | 目标、接触、持有、选择权和反应连续；不能用图标飞行伪装真实递物 |
| 同一条件怎样改变数量、规则或可选行动 | 制度/数量模型：账本、容器、分类框、时间轴 | 保留比较基准；改变条件后显示新状态；分类图注明是否按量绘制 |
| 多个主体怎样相连，影响怎样沿路径传播 | 关系网络：节点、边、路径和条件 | 节点身份持续，边有类型与方向；逐条说明新关系，当前路径清楚；头像无需无关肢体表演 |

从故事切到模型时保留关键对象或字段，让观众看懂它对应哪一项；从小网络扩到大网络时先保留原有相对关系，再添加节点与边。确需重排时让旧图整体移动或明确说明换了视角，避免所有对象一起消失后重新寻找。

涉及权利、承诺或资源转移，检查受益者得到什么、承担者付出什么、履约机制和约束是什么，条件未满足或不履行时会怎样；若有担保，注明主体与范围。视角切换用于补足因果，不为凑角色数量。模型迁移到现实时列出“对应物、仍成立的关系、新增约束、不能照搬之处”；同一字段换了制度后可能有不同规则。

路线卡可以承担“预告问题 → 定位进度 → 判断提醒 → 回答问题”中的不同职责，但每次返回都要填明新增内容。术语侧栏只用于需要累计记忆的内容；关系网络已有完整标签时不再强塞同一套收集界面。

## 写能拍出来的句子

- 先写具体主体、动作和结果，再写抽象结论。每句重要论断都能指出画面里的对象；确实无法图解的说明可以短暂静置，不硬配装饰动作。
- 用观众视角的追问承接章节，但第二人称、故事主角和旁白视角保持一致。旁白中的“你”对应哪个人物要清楚。
- 一句里需要比较多个数时，拆成依次呈现的关系；画面保留共同基准。观众还在读分母时不要提前跳到结论。
- 避免开头堆定义、每段换比喻、连续罗列专业名词、结尾突然加未铺垫的大观点。
- 时长不够时增加有依据的边界、对照或新后果；内容已经闭合就收束，不能增加同义句或循环劳动。

## 为概念建立对象字典

在现有分镜里记录：`概念 → 对象 ID → 形状/颜色/标签 → 状态 → 可做的操作`。同一概念跨镜保持视觉身份；不同概念不能只是同一个图标换名字。

| 解释关系 | 可用的画面操作 | 要检查的事 |
| --- | --- | --- |
| 整体与组成 | 分层容器、堆叠、分拆再合并 | 各部分之和与总量一致，组成颜色持续有效 |
| 存量与流量 | 容器中的量、入口出口、时间步 | 流速与库存不是同一单位，进出改变容器状态 |
| 所有权或归属 | 手持、交接、归属框、凭证 | 交接前后谁拥有物件明确；实体不能凭空复制 |
| 反馈与连锁 | 同一变量变化后触发下一变量 | 箭头有起点终点和含义，不画无意义闭环 |
| 阈值与不可逆结果 | 固定界线、跨线、权限/归属改变 | 先说明界线条件；跨线后状态确实改变 |
| 比例和风险 | 同尺度对照、分子/分母分别变化 | 数值、比例和图形使用同一数据源 |
| 延迟与错过 | 日历、队列、等待者、机会离场 | 时间推进确实改变可选行动，不能只翻日历 |

实体层和说明层分开：角色搬箱子需要接触，解释性的箭头不需要角色拿起来。钱柱或标签的变形是模型动画，不要伪装成发生了实体交易。镜头切换时记录对象的值、位置、持有人和状态，决定继承、重置还是换了一个例子；重置必须让观众知道。

### 道具中有规则，箭头中有关系

- **凭证不是万能纸张。** 写明持有人、相对方、权利、义务、对价、期限和触发条件。某字段被讲到时强调同一位置；后面换现实对象时交代哪些字段保留、哪些条件不同。到期、执行、放弃、转让分别改变相应状态，不能只换标题。
- **空位也有语义。** 虚线槽可表示尚未出现的对象，填入实物表示条件已经满足；先说明虚线的含义。包含关系保留已有内框，再从周围展开外框；若面积不代表数量要标为示意，不能从大框面积读出比例。
- **关系单独建字典。** 每条边记录 `edge_id、source、target、关系类型、方向约定、标签、有效时间、证据`。现金支付、股权持有、服务交付、债权和供货依赖不能共用无标签箭头。图例与标签同时可辨，不只靠颜色区分。
- **分清解释顺序和发生顺序。** 新出现的边可能只是刚被旁白介绍，不代表此刻才发生交易。分镜明确标记“揭示既有关系”或“新事件”，跨镜保留状态。承诺边满足条件前不能沿线流出代表已付的金币。
- **先跟清一条路径，再显示整体。** 引入路径时突出当前边与起终点，旧关系退到背景。整体循环只在观众已看懂各条边后使用，不能靠全网同时流动代替逐条解释。
- **空间位置应有意义。** 同一图标从条件栏移到某一方附近，可以表示它对该方的作用；配明确标签或旁白，不能让位置变化被误读为物件所有权转移。类比网络换成另一种场景时交代对应关系和不适用之处。

## 同一场景持续推进

先铺清场景、人物和规则，再逐次改变条件。观众不需要每句话重新寻找角色。复用场景时保留共同坐标和尺度，突出本次改变，非当前焦点可以适度降对比。

一次主要解释通常按“条件 → 操作 → 可见结果 → 短暂停留/人物反应”组织。反应的职责是指出重要性，不是填空。待机、转向、走近、看结果、退开都可以是有效表演；不能把角色每秒跳一下当作活泼。

相机不跟着所有东西乱跑。需要比较时保持共同画幅；需要看接触时切近景；需要看连锁时展开到多个对象。固定镜头中的对象变化本身就是动画。缩放、摇晃、粒子和大字只强调已有事件，不能代替它。

对照必须标明起点：同一初始条件、改变什么、哪些量不变、结果在哪里分叉。回顾沿用旧对象但压缩过程；升级对照增加新条件。以下二者要区分：

- 有效复用：同一容器先演进出平衡，再演入口变快导致积存，最后演入口恢复后积存仍需时间清空。
- 无效重复：容器一直来回涨落，三段只换字幕说明不同观点。

## 构图与视觉层级

按项目画幅建立背景层、故事层、解释层、界面层和字幕层。参考的小人物模式可以从人物占画高 10%–14% 开始，但图解焦点、近景和不同画幅另行设计，不机械套比例。

- 背景低对比，纹理不与正文争夺注意。像素角色、建筑和图形统一描边、阴影方向与像素尺度；有意混合清晰排版文字可以，但不能把低清位图文字放大糊掉。
- 故事对象按语义排布，不默认全部居中。人看向或走向变化位置，数字尽量贴近被解释的对象。
- 关键标签只写名称、单位或当前数值，推理过程由动画和旁白承担。一个阶段只有一个主要注意焦点；不要让字幕、公式、角色对话与侧栏同时各说一段话。
- 长片采用章节导航时，当前章节保持稳定高亮；概念栏在解释完成后再收录。导航和收录不强制用于短片，不为凑界面塞装饰图标。
- 字幕按语义断句，给下方操作区留空间。以最终发布尺寸和手机横屏缩略预览检查；读不清的关键标签要放大或简化，不能靠观众暂停。
- 系列身份放在克制的位置，原创品牌与角色不能照搬参考账号的标识。

## 真实声音驱动动作

最终旁白确定后，把每个解释段继续分成实际词句对应的事件：`条件起点 → 变化触发 → 结果读出 → 术语命名`。分镜中用稳定的句段 ID 和语义锚点，落实到秒与帧。旁白修改后重建受影响区间，不能沿用旧事件秒数。

动作开始可以略早于结果被读出，但结论所依赖的状态应在读到结果时已经看清。需要等待的相位写入时间轴：例如对象进入后再比较、跨线后再失去控制、盖章后再改变归属。ASR 的词时间是定位辅助，关键点仍要核对；不能把缺失词的平均插值标为精确对齐。

输出帧率与换姿势频率是两回事。步行由位移驱动步态，解释图形可以连续补间。为了“快”而删掉条件、接触或结果停留，会破坏理解；优先压缩废话、重复起步和冗长转场。

## 知识与模型检查

逐条核对事实来源、日期、地区和适用对象。参考作者说过不等于已验证。故事模型中省略的利息、损耗、时间、边界条件等，在可能改变理解的位置交代。

凡有数字演示，先独立算一遍，再用同一状态驱动标签、柱高、箭头和旁白。尤其核对百分比的分母、速率的时间单位、债务与资产口径。历史事件不能被一个简化算式冒充完整原因；类比用于解释某个机制，不代替现实制度和证据。

分类比例图记录统计单位、样本范围、期间、类别定义与来源。流程的结束方式不等于收益或效果分类，例如“完成、取消、超时”不能直接改称“成功、失败”；两种口径要有独立数据。实体库存与账面记录分开建状态，分别定义更新规则；事件确实同时影响两者时才同步修改，不能未经解释就将两者绑定。

对承诺和交易分别记录币种、金额、截至日期、期限、触发条件及状态（宣布、承诺、实付、待履约）。估值、投资额、持股比例、采购额度、实际收入分别建字段；多年合同金额不能直接画成当天现金，也不能直接等同已确认收入。同一笔钱经过多个主体不能重复计作新增资本；现金、股权市值和服务义务不能直接相加。有向闭环只表示已列关系相连，不能仅凭闭环推出必然获利、没有真实收入或损失必然传播。

## 制作前后检查

用 [声画表](SCENE_SCORE_TEMPLATE.md) 检查每段是否新增机制或后果。先完成一个有推理、动作、结果与声音层次的代表样段，再扩全片。最后按时间顺序检查后半段，确认结论越来越具体，而不是场景越来越重复。

静音看画面，能指出对象与变化；只看文案，推理能成立；合声画，事件落点清楚。三种检查各有用途，静音截图不能替代正常速度观看与完整听审。
